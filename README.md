# AllDayRecorder

終日録音用の Android ネイティブアプリ（v0.2）と、録音を PC で日本語文字起こしするツールのセットです。

- 30分ごとに自動分割して保存
- AAC 32kbps
- `INTERNET` 権限なし。データは端末内のみで、アプリ自身は外部送信しません（PC へ渡すときは、利用者が共有シートで OneDrive などを選びます）

## アプリの機能

- **共有**: 一覧の行をタップまたは長押しすると共有シートが開きます。録音中のセグメントは送れません（停止後に送れます）。
- **全て書き出し**: 「全て書き出し（Music/AllDayRecorder）」ボタンで、全セグメント（録音中のセグメントを除く）を端末の `Music/AllDayRecorder` へコピーします。
- **停止時の自動コピー**: 「停止」を押すと、その日の分が自動で `Music/AllDayRecorder` へコピーされ、「今日の分を送る」ボタンが表示されます。

## 使い方

0. 初回のみ: 受信フォルダ `日々のコンテキスト\_録音受信` がまだ OneDrive に無ければ、PC で `pc_tools\文字起こし実行.bat` を一度実行して作成する（自動で作られます）。手で作っても構いません。
1. アプリで「開始」を押して録音する（30分ごとに自動で分割保存されます）。
2. 録音を終えるときは「停止」を押す。その日の分が `Music/AllDayRecorder` へ自動コピーされ、「今日の分を送る」ボタンが出ます。
3. 「今日の分を送る」を押し、共有シートで OneDrive を選んで `日々のコンテキスト\_録音受信` に保存する。
4. PC で OneDrive の同期が終わったら、`pc_tools\文字起こし実行.bat` を実行する。
5. 結果は OneDrive の `日々のコンテキスト\YYYY-MM-DD\` にできます。
   - セグメント別の `.txt`
   - その日の全文を時刻順に結合した `context.txt`

## PC側ツール（pc_tools）

- `transcribe_daily.py` 本体と、起動用の `文字起こし実行.bat`
- 入力: OneDrive `日々のコンテキスト\_録音受信` 内の `.m4a`
- 文字起こし: faster-whisper（GPU）で日本語文字起こし
- 出力: OneDrive `日々のコンテキスト\YYYY-MM-DD\` に、セグメント別 `.txt` と結合版 `context.txt`
- 一度処理したファイルは二重に処理しません。
- 失敗したファイルは飛ばして処理を続け、記録に残します（`日々のコンテキスト\_報告\transcribe_log.txt`）。

## 導入・更新方法

1. 新しい APK を OneDrive 経由でスマホで開く。
2. そのまま**上書きインストール**する。

> **注意: 先にアンインストールしないこと。**
> アンインストールすると `Android/data` 内の録音が消えます。更新は必ず上書きインストールで行ってください。

## 検証状況

- Android 14 と Android 9 の両エミュレータで実測済み。
- 上書きインストールを実測済み（旧版＋録音ありの状態に新版を上書きし、録音が全件残ることを確認）。
- 2026-11-24 に実機（Galaxy Z Fold7）へ導入し、当日の録音23件が保持されたことを確認。

## 既知事項

- **F4**: 作り直し途中の旧形式ファイルが残っている特殊な条件でのみ、`context.txt` の内容が二重になります。実運用では起きません。
- **`文字起こし実行.bat` の終了コード**: 失敗時に終了コードを返しません。手動実行では影響なし。タスクスケジューラなどから自動実行する場合のみ、失敗を検知できない影響があります。
