# AllDayRecorder

終日録音用の Android ネイティブアプリ（フォアグラウンドサービス、type=microphone）。
30分ごとに自動分割保存、AAC 32kbps（24h ≒ 345.6 MB）、データは端末内のみ。
外部送信・クラウド保存はしません（`INTERNET` 権限なし）。PWA では画面オフ・折りたたみ時の終日録音を維持できないため、Android ネイティブ方式です。

## 現在の状態

- 静的検証済み: フォアグラウンドサービス登録、30分分割保存、32kbps 設定、一覧表示、外部送信なし
- ビルド・実機確認は未実施（開発 PC に Android SDK / gradle / adb がない）
- 日本語文字起こしは未実装

## 使い方

1. Android Studio で開いてビルド
2. 録音権限（Android 13 以降は通知権限）を許可
3. 「開始」で録音開始。保存済みセグメントは一覧に表示される
